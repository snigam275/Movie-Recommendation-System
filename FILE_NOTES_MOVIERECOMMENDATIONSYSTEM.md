# MovieRecommendationSystem - File Notes

Date: 2026-04-08
Scope: Project files only (excluded deep analysis of .venv, .git internals, .idea internals)

## 1) System Overview

This project has two main phases:
1. Offline model build phase
2. Runtime serving phase

Offline build phase:
- build_model.py reads CSV files from DataSetFolder.
- It creates features, vectorizes text, computes cosine similarity.
- It writes movies_dict.pkl and similarity.pkl into Movies-Recommender-System.

Runtime serving phase:
- server.py (Flask) and app.py (Streamlit) both load movies_dict.pkl and similarity.pkl.
- Static UI files under Movies-Recommender-System/static call Flask API endpoints.
- External movie metadata/posters come from TMDB and OMDB APIs.

## 4) Dependency and Relationship Map

Data and build chain:
- tmdb_5000_movies.csv + tmdb_5000_credits.csv -> build_model.py -> movies_dict.pkl + similarity.pkl

Serving chain (Flask + static):
- server.py -> serves index.html/recommend.html and APIs
- recommend.html -> app.js -> calls server.py APIs -> reads pickles in backend
- style.css -> styles both pages

Serving chain (Streamlit):
- app.py -> directly loads pickles and calls external APIs

Secrets chain:
- .env -> app.py and server.py for API keys

## 5) Important Risks and Priority Insights

1. Critical
- requirements.txt does not include flask/flask-cors though server.py requires both.
- .env is empty in current snapshot, so external API metadata/posters may fail.
- similarity.pkl is large (~177 MB), which impacts memory and startup.

2. High
- Two runtime paths (app.py Streamlit and server.py Flask) can confuse deployment if not documented.
- poster_cache in server.py is in-memory and unbounded.

3. Medium
- Notebook and checkpoint files can drift from script behavior if not synchronized.

## 6) Quick Run Guidance

Model generation:
- Run build_model.py when dataset or feature logic changes.

Flask route:
- Install dependencies (including flask + flask-cors), then run server.py.
- Open landing page and recommendation UI from served static routes.

Streamlit route:
- Run app.py with streamlit for all-in-one app experience.
